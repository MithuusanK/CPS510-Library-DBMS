# CPS510-Library-DBMS

Library Database Management System (Flask + Oracle)

This project is a simple web-based Library Database Management System built with Flask and Oracle Database.
It allows users to view information such as library members, admins, and books directly from an Oracle database through a clean web interface.

Features

View Library Members

View Library Admins

View Books

Extendable to DVDs, specific users, or specific items

Interactive frontend with modal display for query results

RESTful backend API returning JSON responses

Oracle Database integration using cx_Oracle

Technologies Used
| Component          | Technology            |
| ------------------ | --------------------- |
| Backend            | Flask (Python)        |
| Database           | Oracle Database       |
| Database Connector | cx_Oracle             |
| Frontend           | HTML, CSS             |
| API Format         | JSON                  |
